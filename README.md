# Deniks20 Stitches

A static storefront for Malaysian hijabs and ready-to-wear modest fashion. Customers browse style examples on the storefront and enquire about availability and pricing through WhatsApp.

## Local preview

Run `python3 -m http.server 8000 --directory site` from the repository root and open `http://localhost:8000`.

## Deployment

In GitHub repository settings, select **Pages → Build and deployment → Source → GitHub Actions**. Push to `main` or manually run **Deploy storefront to GitHub Pages** in the Actions tab. The deployment job reports the public URL.

The logo is a vector recreation of the supplied profile monogram. The hero and catalogue images are illustrative.
